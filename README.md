# cad-projects

A playground for learning [CadQuery](https://cadquery.readthedocs.io/) and experimenting with parametric CAD models in Python.

## Goals

- Learn CadQuery fundamentals through small, self-contained projects
- Build up a library of reusable parts and parametric scripts
- Export models to STL/STEP for printing or further use

## Structure

Each project lives in its own subdirectory with a script that generates the model.

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install cadquery
```
